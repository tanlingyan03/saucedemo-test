# SauceDemo 电商系统功能测试实践

对 [SauceDemo](https://www.saucedemo.com) 演示电商网站进行完整功能测试，覆盖登录认证、商品浏览、购物车、结算流程等核心模块。

## 🔍 测试范围

|   模块   |                                           测试内容                                   |
|----------|--------------------------------------------------------------------------------------|
| 登录认证 | 6 种用户角色（standard / locked_out / problem / performance_glitch / error / visual） |
| 商品列表 |                         排序、加购、移除、图片展示、布局                              |
|  购物车  |                            商品核对、移除、空车、返回                                 |
| 结算流程 |                         正常流、空值校验、取消、税费计算                              |
| 异常场景 |                           未登录访问、特殊字符、性能卡顿                              |
